# ⭐ 2026 더드림 성경 암송 파티 (Super Bible Verse Party)

[![CI](https://github.com/danielKim614/super-bible-verse-party/actions/workflows/ci.yml/badge.svg)](https://github.com/danielKim614/super-bible-verse-party/actions/workflows/ci.yml)

**교회 성경 암송 대회를 위한 마리오 파티 컨셉의 웹 앱**입니다.

마리오 파티의 보드게임 진행 방식(주사위 → 이동 → 칸 이벤트 → 코인으로 스타 구매)을 그대로 오마주하되,
코인 대신 **달란트**를 쓰고, 칸에 도착할 때마다 그 칸에 해당하는 **로마서 8장(새번역) 구절을 암송**해서
달란트를 얻는 게임입니다. 가장 많은 스타를 모은 팀이 우승합니다.

- 6팀이 교회 앞에서 **실물 주사위**를 굴리고, 실물 달란트를 주고받습니다.
- 진행 오퍼레이터가 **어드민 화면**에 주사위 값과 암송 결과만 입력하면, 이동·보상·스타·아이템은 시스템이 자동 계산합니다.
- 게임판과 애니메이션은 앞 스크린(메인 화면)에만 나오고, 참가자 **휴대폰**에는 지금 차례·순위·소식이 실시간으로 동기화됩니다.

> 마리오 파티의 분위기와 규칙을 참고했을 뿐, 닌텐도의 캐릭터·이미지·로고는 사용하지 않습니다. 게임말은 각 팀 리더 사진입니다.

## 게임 규칙 요약

전체 규칙(숨은 규칙 포함)은 어드민의 **설명서** 탭에 현재 설정값과 함께 정리되어 있습니다.

| 항목 | 내용 |
|---|---|
| 보드 | 로마서 8장 1~39절 = 39칸, 갈림길 3곳(2·15·30절)과 합류 칸(11·28·39절) |
| 진행 | 기본 8턴, 실물 주사위 2개(설정에서 변경), 진행 순서는 시작 전에 운영자가 지정 |
| 암송 | 도착한 칸의 절을 팀원이 나와서 암송, MC가 판정 (제한시간 없음) |
| 보상 | 일반 칸 +3 / 어려운 칸 +5 / 이벤트 칸 +6 / 선물 칸 +3 (+랜덤 아이템) |
| 2배 | 마지막 3턴, 해프닝 "황금 라운드" |
| 스타 | 보드 위 2개, 20달란트. 멈추거나 **지나가기만 해도** 바로 구매(암송과 무관) |
| 상점 | 28절로 들어가기 직전(바깥길·지름길 합류점). **지나갈 때** 아이템 구매 |
| 보너스 스타 | 게임 종료 후 암송 스타 · 달란트 스타 · 도전 스타 |
| 뺏기 | 없음 |

### 보드

```
START → 1~2 ─┬─ 3~6 (윗길) ───┬─ 11~15 ─┬─ 16~22 (바깥길) ─┬─ 🛸상점 ─ 28~30 ─┬─ 31~34 (왼쪽길) ─┬─ 39 → 1
             └─ 7~10 (아랫길) ┘          └─ 23~27 (지름길) ─┘                  └─ 35~38 (안쪽길) ─┘
```

출발(START)은 칸이 아닙니다. 39절에서 계속 가면 바로 1절로 이어집니다.

### 칸 종류

- 🔵 **일반 칸**: 장절을 보고 그대로 암송
- 🔴 **어려운 칸**: 긴 구절. 빈칸 채우기 / 첫 단어만 보고 / 힌트 없음 (칸마다 고정)
- 🟢 **이벤트 칸**: 한 사람이 2절 연속(다음 절까지) 또는 3절 연속(앞뒤 절 포함)
- 🎁 **선물 칸**: 성공 시 아직 없는 종류 중 랜덤 아이템 (가방이 가득 차 있으면 +3 달란트)
- ❔ **해프닝 칸**: 멈추면 사건 발생 (스타 대이동 / 달란트 비 / 황금 라운드 / 깜짝 선물), 이후 일반 칸처럼 암송
- 💗 **축복 칸**: 멈추면 꼴찌 팀에게 +5 달란트, 이후 일반 칸처럼 암송

### 아이템 (팀당 최대 3개, 같은 아이템은 하나씩만)

| 아이템 | 효과 | 가격 |
|---|---|---|
| 트리플 다이스 | 이번 턴에 주사위 3개를 굴림 | 5 |
| 선택 다이스 | 두 주사위 중 하나의 눈을 직접 정함 | 3 |
| 워프 파이프 | 다른 칸으로 위치를 랜덤 이동 | 5 |
| 황금 파이프 | 원하는 칸으로 이동 | 10 |
| 달란트 2배권 | 굴리기 전에 사용, 이번 턴 암송 보상 2배 | 3 |
| 힌트권 | 막힌 지점의 다음 단어 1회 | 2 |
| 스타 할인권 | 스타를 10달란트에 구매 | 5 |

이동 아이템과 달란트 2배권은 주사위 굴리기 전에, 힌트권은 암송 중에 사용합니다.

## 화면

| 경로 | 누가 | 설명 |
|---|---|---|
| `/display` | 앞 스크린 | 보드, 말 이동 애니메이션, 순위, 암송 카드, 시상식. 참가 QR 코드 표시 |
| `/` (= `/join`) | 참가자 휴대폰 | 팀 선택 후 지금 차례·순위·소식 관전 (게임판은 앞 스크린에만) |
| `/admin` | 진행 오퍼레이터 | 주사위·암송 결과 입력, 되돌리기, 강제 개입, 달란트 장부, 팀 관리, 설정 |

어드민 주요 기능

- **되돌리기 / 다시**: 모든 입력은 이벤트 로그로 저장되어 몇 단계든 되돌릴 수 있습니다. 실물 달란트를 다시 주고받아야 하면 안내가 뜹니다.
- **강제 개입**: 달란트·스타·아이템·위치·스타 위치·턴 수·2배 구간·현재 차례를 직접 조정
- **MC 안내**: 매 턴 "지급 6달란트 (5×1, 1×1)"처럼 실물 권종(1/5/10)까지 안내
- **달란트 장부**: 모든 증감 내역과 팀별 "실물 확인" 체크

## 시작하기

### 1. 설치

```bash
npm install
cp .env.example .env.local   # Supabase URL / anon key 입력
npm run dev
```

### 2. Supabase 준비

1. Supabase 프로젝트 생성 (Data API 켜기, 새 테이블 자동 노출은 끄기, 자동 RLS 켜기)
2. **SQL Editor**에 [`supabase/migrations/0001_init.sql`](supabase/migrations/0001_init.sql)을 붙여 넣고 실행
   - 맨 아래 `'change-me'` 를 원하는 **어드민 패스코드**로 바꾼 뒤 실행하세요
   - 이어서 [`0002_verses.sql`](supabase/migrations/0002_verses.sql)도 실행
   - 이어서 [`0003_version.sql`](supabase/migrations/0003_version.sql), [`0004_hardening.sql`](supabase/migrations/0004_hardening.sql)도 순서대로 실행
3. `.env.local`에 Project URL과 anon(publishable) key 입력

### 3. 본문 입력

저작권 때문에 새번역 본문은 저장소에 포함되어 있지 않습니다.
`supabase/migrations/0002_verses.sql`도 SQL Editor에서 실행한 뒤, 어드민 > **본문** 탭에 새번역 로마서 8장을 통째로 붙여 넣고 저장하세요. (각주 번호·소제목은 자동 제거)

### 4. 팀 사진

리더 사진을 `public/teams/` 에 넣고 어드민 > 팀·참가자에서 `/teams/파일명.jpg` 로 입력합니다.

### Supabase 없이 미리 해보기 (로컬 데모)

주소 뒤에 `?demo=1` 을 붙이면 같은 브라우저의 탭끼리만 동기화되는 데모 모드로 실행됩니다. 어드민 패스코드는 `demo`.

```
http://localhost:3000/admin?demo=1
http://localhost:3000/display?demo=1
```

## 구조

```
src/
  game/          게임 규칙 (순수 TypeScript)
    board.ts       39칸 보드·다섯 길·칸 유형·좌표
    items.ts       아이템 정의
    reducer.ts     이벤트 → 상태 (이동, 갈림길, 스타, 암송, 보상, 시상식)
    types.ts       설정·이벤트·상태 타입
    verses.ts      본문 도우미 (본문 자체는 DB verses 테이블)
  lib/
    backend.ts     Supabase / 로컬 데모 백엔드
    useGame.ts     실시간 구독 + 어드민 동작(되돌리기 등)
  components/    보드 SVG, 순위표, 암송 카드, 시상식
  app/           /display, /join, /admin
supabase/migrations/   DB 스키마·RLS·어드민 함수
scripts/test-reducer.ts  규칙 시나리오 테스트 (npm run test:reducer)
```

게임 상태는 DB에 직접 저장하지 않고, `events` 테이블의 입력 기록을 모든 화면이 같은 리듀서로 재생해서 계산합니다.
그래서 되돌리기가 안전하고, 어느 화면에서 새로고침해도 같은 상태가 나옵니다.
